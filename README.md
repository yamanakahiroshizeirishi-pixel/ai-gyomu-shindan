# AI業務自動化 診断レポート作成ツール

報告会でお渡しする「診断レポート（改善仕様書）」を作成するアプリです。
**入力は「業種」「従業員数」「無駄と感じている業務」の3問だけ。**残りは業種別の標準値から自動で推計します。
インストール不要・インターネット接続不要。`index.html` をダブルクリックすれば起動します。

---

## 使い方

1. `index.html` をダブルクリック（Chrome / Edge 推奨）
2. **Q1** 事業内容（業種）のカードを選ぶ
3. **Q2** 従業員数のボタンを選ぶ
4. **Q3** 特に「時間の無駄」と感じている業務をクリックで選ぶ（複数可・**スキップ可**）
5. **Q4** レポートが完成 → `印刷 / PDFで保存` → 印刷ダイアログで「PDFとして保存」

会社名・担当者名・報告会の日付・診断実施者などの入力欄は廃止し、業種名で自動的に表記します（例：表紙は「建設・工事業 経営者 様」）。

### Q3「無駄と感じている業務」の選択

選択肢は**選んだ業種に応じて自動で切り替わり**、2グループに分かれて表示されます。

- 「〇〇業ならではの業務」… その業種特有の業務（例：飲食業なら「予約・電話対応」「仕入発注・原価計算」）
- 「どの業種にも共通する業務」… 見積書作成、問い合わせ対応、議事録作成など

ボタンには業務名と分類だけを表示し、数字は出しません（ヒアリング中に数字へ意識が向かないようにするためです）。選んだ業務は次のように反映されます。

- 優先順位のスコアが2.5倍になり、報告書の**上位に配置**される
- 報告書に「**特に負担を感じているとお伺いした業務**」の専用ページが追加される
- 業務一覧に「重点」バッジが付く
- **実演デモの対象**が原則ここから選ばれる

### 自動で推計される内容

業種を選んだ時点で、次のすべてが自動的に決まります。

| 推計されるもの | 根拠 |
|---|---|
| 対象となる業務（10件前後） | 業種特有の業務＋その業種で負担の大きい共通業務 |
| 各業務の月間作業時間 | 業種標準値 × 従業員規模の係数 |
| 各業務の削減率・難易度 | 業務ごとに設定済みの標準値 |
| 人件費の時間単価 | 業種別（例：士業3,500円／飲食2,200円） |
| 商談所要時間・成約率・平均取引額 | 業種別の標準値 |
| 想定される経営課題・使用ツール | 業種特性から自動選択 |
| 実演するデモ業務 | Q3で選んだ重点業務を優先し、効果と着手しやすさから自動選択 |

推計値であることは報告書にも明記されます（「作業時間の把握方法：業種・従業員規模にもとづく標準値からの推計」）。
数字を1つでも書き換えると「ヒアリング結果にもとづく調整値」に切り替わります。

## ヒアリング結果を反映したいとき

Q4の **「ヒアリング結果に合わせて内容を調整する」** を開くと、4つのタブで微調整できます。
変更するとレポートは即座に再計算されます。

| タブ | できること |
|---|---|
| 対象業務と時間 | 業務のチェック増減、月間時間の書き換え、業務の追加、「推計値に戻す」（重点業務には「重点」バッジ） |
| 経営課題 | 想定課題の変更、ヒアリング内容の自由記述、使用ツールの選択 |
| 効果試算の前提 | 時間単価・営業充当率・商談所要時間・成約率・平均取引額・初期投資 |
| 実演する業務 | デモ対象業務の変更 |

## 出力される報告書の内容（A4・約19〜22ページ）

1. 表紙（削減時間・年間コスト削減額・売上インパクトの3大数字）
2. 現状の整理（会社概要／この業種で一般的に起きていること／課題／診断の結論）
3. 特に負担を感じているとお伺いした業務（Q3で選択した場合のみ）
4. 自動化できる業務の一覧（削減時間・年間効果額つき）
5. 着手する順番の考え方（棒グラフ＋効果×難易度マトリクス）
6. 優先度の判定ルールと段階別の内訳
7. **業務別：AIの使い方と削減時間**
   - 使うAI活用の型 ／ AIをどう使うか ／ 使用するツール ／ 最初の一歩（今週できること）
   - 現状◯h → 導入後◯h → 削減◯h → 年間効果額
8. 削減効果の試算（投資回収期間を含む）
9. 生まれた時間による売上インパクト
10. 実行ロードマップ（90日・3段階）と推進チェックリスト
11. 報告会で実演する自動化の仕様（As-Is / To-Be・仕様概要・導入手順）
12. 導入にあたっての留意点／次のアクション

AI活用の型は6分類（生成AI／AI-OCR／AI自動応答／業務フロー自動化／データ集計の自動化／音声AI）で、
業務ごとに該当する型と削減率の目安が自動で割り当てられます。

## 数字の考え方

| 項目 | 計算式 |
|---|---|
| 月間削減時間 | 各業務の「月間時間 × 削減率」の合計 |
| 年間コスト削減額 | 月間削減時間 × 12 × 時間単価 |
| 正社員換算 | 年間削減時間 ÷ 1,800時間 |
| 投資回収期間 | 初期投資 ÷（年間削減額 ÷ 12） |
| 売上インパクト | 削減時間 × 営業充当率(30%) ÷ 商談所要時間 × 成約率 × 12 × 平均取引額 |

売上インパクトは業種の実態に合わせて商談工数を設定しています
（例：建設25時間/件、IT20時間/件、飲食0.5時間/件）。過大な数字が出ないよう営業充当率は30%を既定にしています。

## ボタンの説明

| ボタン | 動作 |
|---|---|
| 保存 / 読込 | 入力内容をブラウザに保存・復元（自動保存も動作） |
| 最初から | 入力内容をすべて消去してQ1に戻る |
| 印刷 / PDFで保存 | 印刷ダイアログを開く（PDFとして保存を選択） |
| HTMLで保存 | レポート単体のHTMLファイルを書き出す（メール添付で配布可） |

## ファイル構成

```
index.html          画面の骨組み（4ステップ）
css/style.css       入力画面のスタイル
js/data.js          業種マスタ・業務マスタ（14業種 / 約90業務）＋業種別の推計パラメータ
js/report-css.js    レポートのスタイル（画面・印刷・書き出しで共通）
js/report.js        計算ロジックとレポート生成
js/app.js           画面の動き（自動推計・ステップ移動・保存・出力）
.claude/launch.json ローカル確認用サーバー設定（通常は使いません）
```

### 推計値を変えたいとき

`js/data.js` の末尾 `INDUSTRY_DEFAULTS` に業種別のパラメータがまとまっています。

```js
shigyo: {
  rate: 3500,        // 人件費の時間単価（円）
  perdeal: 5,        // 商談・顧客獲得1件あたりの所要時間
  close: 25,         // 成約率（％）
  deal: 400000,      // 顧客1件あたりの平均取引額（円）
  commons: [...],    // 自動で対象に含める共通業務のID
  tools: [...],      // 想定される使用ツール
  issues: [...],     // 想定される経営課題
  note: '...'        // 「この業種で一般的に起きていること」の文章
}
```

業務そのものを追加・変更する場合は同ファイルの `T(...)` を編集します。

```js
T('id', '業務名', '分類', 月間時間, 削減率, 難易度, ['使用ツール'], 'AIをどう使うかの説明',
  ['現状の手順1','現状の手順2'],        // 任意
  ['自動化後の手順1','自動化後の手順2']) // 任意
```

- 分類は `営業` / `顧客対応` / `経理・財務` / `人事・労務` / `社内管理` / `現場業務`
- 削減率は 0〜1（0.7 = 70%削減）／ 難易度は 1=低 / 2=中 / 3=高

---

## 注意事項

- 作業時間・削減率は同業・同規模の標準値からの推計です。ヒアリング後は調整パネルで実態に合わせてください。
- 売上インパクトは「生まれた時間を営業に充当した場合」の試算であり、成果を保証するものではありません。
- これらの前提は報告書にも注記として印字されます。

## 他の人と共有する（共有リンク）

このアプリは、リンクを送るだけで相手のブラウザでもそのまま動く「共有リンク」として公開できます。
最新の共有リンクはこちらです（クリックで開けます）：

**https://claude.ai/code/artifact/87f70884-bf5a-4f16-8956-d5fe03e70148**

- リンク先はアプリそのものです。相手も業種を選ぶところから使えます。
- 相手の環境では「HTMLで保存」ボタンは、ブラウザのダウンロード確認を経由して保存されます（保存できない環境では「印刷 / PDFで保存」をご案内するメッセージが出ます）。
- 「印刷 / PDFで保存」はどの環境でも同じように使えます。

### 共有リンクを更新したいとき

見た目やロジックを変更した後、共有リンクにも反映したい場合は次の手順です。

```bash
python build-artifact.py
```

`js/data.js` `js/report.js` `js/app.js` `css/style.css` `index.html` の内容を1つのファイル（`artifact.html`）にまとめて出力します。
このファイルをArtifactとして再公開すると、同じ共有リンクの内容が更新されます（Claude Codeに「共有リンクを更新して」と伝えてください）。

共有リンクはローカルの `index.html` と完全に同じ内容・同じ挙動です（保存方法だけ環境に応じて自動的に切り替わります）。
